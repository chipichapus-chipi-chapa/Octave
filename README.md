# 🎹 Octave — Информационная система музыкальной студии (WPF)

Настольное приложение (Desktop Application) на платформе .NET для автоматизации процессов бронирования, аренды оборудования и записи на курсы в музыкальной студии. Проект разработан в рамках курсовой работы.

## 🚀 Стек технологий (Tech Stack)
* **Framework:** WPF (Windows Presentation Foundation), .NET.
* **Язык программирования:** C# (чистая объектно-ориентированная логика).
* **Архитектура интерфейса:** XAML (разметка окон и стилей), привязка данных (Data Binding), концепция MVVM.
* **Инструменты:** Git, Visual Studio, Figma (для первоначального проектирования UX/UI интерфейса).

## 🛠️ Функциональные возможности
* **Управление тайм-слотами:** Бизнес-логика проверки пересечений времени при аренде репетиционных залов и инструментов.
* **Разграничение прав доступа:** Системные роли (клиент, преподаватель, администратор студии).
* **Каталог услуг:** Динамическая фильтрация и поиск доступных музыкальных инструментов и курсов внутри интерфейса.
* **UX/UI и стилизация:** Интерфейс полностью спроектирован в Figma и реализован на XAML с кастомными стилями элементов управления.

## 📦 Развертывание и запуск (Installation)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл решения `kurs_musik_club.sln` в Visual Studio.
3. Скомпилируйте и запустите проект (Build -> Start Debugging).
